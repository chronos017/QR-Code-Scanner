Employee QR Scanner

Event Check-in / Regular Verification

Scan an employee QR code and record their attendance for an event.
Point the camera at the employee QR code.
How to use:

Event Check-in
Select Event Check-in, enter the event name, then scan the employee QR code. The system will validate the employee and record the check-in.

Regular Verification
Select Regular Verification to verify an employee without recording an event check-in.

Important:
The employee name and employee code printed inside the QR are informational. The secure QR token is what the server uses for authentication.
